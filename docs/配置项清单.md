# 配置项清单

手机上「设置」app 可调项 + 代码内尚未暴露的常量，一页看清。
默认值都是实测调顺的值，非必要不动。

## 一、设置 app 可调（存聊天变量，明文随卡走；自定义密钥例外，仅存本机浏览器）

### 生成 API（`custom_api`，作用于每一次手机独立生成）

| 模式 | 行为 |
|---|---|
| 跟随正文（默认） | 不传 `custom_api`，完全用酒馆当前选的来源/模型/预设 |
| 只换模型 | 来源与参数跟随酒馆，仅覆盖模型名 |
| 自定义 API | 完全独立的中转（地址/密钥/模型）。**API 源可选**：OpenAI 格式（第三方中转）或 Google AI Studio 格式（配反代地址）——即自定义模式也能走谷歌格式，不是只能 OpenAI。**可存多套预设**（源+地址+模型，密钥按预设名各存一份在本机浏览器），点按即整套套用 |

### 提示词携带（手机生成时，全部即时生效）

| 设置项 | key | 默认 | 说明 |
|---|---|---|---|
| 带几楼正文 | plotFloors | 8 | 「主线近况」带最近几楼正文（剥状态栏/思维链/HTML，每楼截断） |
| 每楼最多带多少字 | plotCap | 900 | 单楼上限，截断尽量落行边界 |
| 私聊记录带几条 | histPriv | 50 | 与对方的微信记录条数 |
| 群聊记录带几条 | histGroup | 50 | 该群的记录条数 |
| 顺带带几个相关会话 | crossMax | 3 | 跨会话个数上限 |
| 每个相关会话带几条 | crossLines | 18 | 每个跨会话的尾巴长度 |

**跨会话是什么**：生成私聊时，顺带带对方「今天在的群」的群记录；生成群聊时，顺带带成员「今天与机主的私聊」。让对方接得上别处的梗，但有防开天眼规则兜着（别人不知道的私聊禁止引用）。
**时间限制**：跨会话只看当天；主线近况不限时间、只限楼数。

### 正文生成 · 手机注入（正文 AI 对手机的知情度，即时生效）

正文每一楼生成前，把最近聊过的手机会话塞进去，让正文的 AI 知道手机上发生过什么：

| 设置项 | key | 默认 | 说明 |
|---|---|---|---|
| 聊过几楼内就注入 | injRecent | 8 | 会话在主线最近 8 楼内聊过 → 注入 |
| 点名几楼内就注入 | injMention | 4 | 对方名字出现在主线最近 4 楼 → 注入（哪怕聊得早） |
| 一次最多注入几个会话 | injMax | 3 | 按最近活跃优先 |
| 每会话注入最近几条 | injRounds | 20 | 约 10 轮 user+对方 |

## 二、代码内常量（暂未暴露到设置 app，改动需改源码）

### 聊天记录压缩（`engine.js` → `compress`）

单会话记录太长时，把窗口外的旧消息折成提要，提示词只带最近原文 + 提要：

| 常量 | 默认 | 说明 |
|---|---|---|
| COMPRESS_AT | 60 | 未折叠超过 60 条触发折叠 |
| DIGEST_KEEP | 50 | 最近 50 条原样携带，更早的折成提要 |

注意：提要一旦生成就固定文本，之后调携带量不会重折。想完全重算请清空该会话记录。
